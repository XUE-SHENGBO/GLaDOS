# 测试文件

每个测试主题建一个目录，例如 `emotion/`、`audio/`、`oled/`，同主题的脚本、输入数据和说明放在一起。

- Python 测试脚本推荐命名为 `test_功能名.py`。
- 小型输入数据可以放在主题目录下的 `fixtures/`。
- 实际测试结果写入 `results.md`；截图也放在同一主题目录内。
- 说明需要哪些依赖、是否需要 ROS 2 或真实硬件，以及具体运行命令。

目前此目录只有组织框架，尚未包含可执行的个人测试。可以复制 [测试记录模板](../templates/test-record.md) 作为主题目录的 `README.md`。
